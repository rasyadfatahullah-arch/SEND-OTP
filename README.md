# JIYYAD TOOLS — Send OTP

Kirim OTP ke nomor WhatsApp · iOS 26 Liquid Glass

## Jalankan

```bash
npm install
npm start
```

Buka: **http://localhost:3000**

## Fitur

- Form input nomor WA (format 628xxx)
- Proxy aman ke `api.jerexd.my.id` (apikey tersembunyi di server)
- Tema iOS 26 frosted glass
- Dark mode otomatis
